# 💻 C++ Practice Programs

A collection of C++ programs written for practice, covering basic logic building, pattern printing, searching and sorting, and core data structures.

## Contents

### Basics
`sum` · `even or odd` · `calculator` · `fibonacci` · `prime` · `prime (1 to n)` · `nCr` · `power of a and b` · `upper_lower_digit`

### Number Conversions
`Decimal to Binary` · `binary_to_decimal`

### Palindromes
`integer palindrome` · `string palindrome`

### Patterns
`pattern1` to `pattern26` (star, number and character patterns)

### Arrays
`reverse the array` · `Second max` · `Pivot in array` · `swap alternate` · `threesum` · `No. of notes`

### Searching & Sorting
`linear_search` · `Bubble sort` · `selection sort`

### Linked Lists
`linked list 1` · `linked list 2` · `doubly linked list`

### Stacks & Queues
`stack using array` · `stack using list` · `reverse using stack` · `queue reverse` · `queue interleave` · `Celebrity problem`

### Trees
`Building tree` · `BST`

## How to Run

```bash
g++ "Bubble sort.cpp" -o bubble
./bubble          # Windows: bubble.exe
```

Replace the filename with any program in the repo.

## Requirements

- A C++ compiler (g++, clang, or MinGW)

## Purpose

Personal practice for programming fundamentals and data structures and algorithms (DSA).
